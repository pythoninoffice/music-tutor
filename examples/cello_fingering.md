# Axel F – cello fingering

Everything stays in **1st position** – no shifts needed.
Fingers: 0 = open string, 1 = index, 2 = middle, 3 = ring, 4 = pinky, b1 = 1st finger stretched back a half step (backward extension).
Strings: C (C2), G (G2), D (D3), A (A3). Format below: note (string, finger).

## Notes used

- A2 = G string, finger 1
- C3 = G string, finger 4
- D3 = D string, finger 0
- E3 = D string, finger 1
- F3 = D string, finger 2
- F#3 = D string, finger 3
- G3 = D string, finger 4
- A3 = A string, finger 0
- Bb3 = A string, finger b1
- D4 = A string, finger 4

## Bar by bar

- **Main bar 1:** D3 (D string, 0)  F3 (D string, 2)  D3 (D string, 0)  D3 (D string, 0)  G3 (D string, 4)  D3 (D string, 0)  C3 (G string, 4)
- **Main bar 2:** D3 (D string, 0)  A3 (A string, 0)  D3 (D string, 0)  D3 (D string, 0)  Bb3 (A string, b1)  A3 (A string, 0)  F3 (D string, 2)
- **Main bar 3:** D3 (D string, 0)  A3 (A string, 0)  D4 (A string, 4)  D3 (D string, 0)  C3 (G string, 4)  C3 (G string, 4)  A2 (G string, 1)  E3 (D string, 1)  D3 (D string, 0)
- **Main bar 4 (keep holding the D3 from bar 3, then):** D3 (D string, 0)  D3 (D string, 0)
- **Middle bars 1 & 3:** G3 (D string, 4)  F#3 (D string, 3)  F3 (D string, 2)  F3 (D string, 2)  E3 (D string, 1)  E3 (D string, 1)
- **Middle bar 2:** G3 (D string, 4)  F#3 (D string, 3)  F3 (D string, 2)  F3 (D string, 2)  E3 (D string, 1)  E3 (D string, 1)  E3 (D string, 1)
- **Middle bar 4:** G3 (D string, 4)  F#3 (D string, 3)  F3 (D string, 2)  F3 (D string, 2)  D3 (D string, 0)  D3 (D string, 0)
- **Ending bar 3:** D3 (D string, 0)  A3 (A string, 0)  D4 (A string, 4)  D3 (D string, 0)  C3 (G string, 4)  C3 (G string, 4)  A2 (G string, 1)  E3 (D string, 1)  D3 (D string, 0)
- **Final note:** D4 (A string, 4)

Order: main theme ×2, middle part ×2, ending (main bars 1–3, hold D3 a bar, then D4).
Tips: the middle part (G3 F#3 F3 E3 = D4 D3 D2 D1) is a walk down one finger at a time on the D string.
For Bb3 (A b1) slide the 1st finger back a half step from its normal B spot; let it come back for E3/A2 afterwards.
